# Pixel Forge

A pocket pixel art studio that runs entirely in your browser.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/pixel-forge/

Features: pencil with line interpolation, bucket fill, eraser, canvas color picker, mirror-X mode,
32-color curated palette plus custom colors, 16/24/32 grids, 40-step undo, live preview, one-tap
crisp PNG export. Pure client-side HTML/CSS/JS - nothing is uploaded anywhere.
